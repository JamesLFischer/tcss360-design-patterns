# Software Design Pattern Activities

Short Java activities by James Fischer from a software development and quality assurance course (TCSS 360, 2026).

| Folder | Pattern |
|---|---|
| `singleton-activity` | Thread-safe logger, shown with and without the Singleton pattern |
| `serialization-activity` | Saving objects with Java serialization vs. a hand-written manual save |
| `factory-pattern-shapes` | Shape factory with UML diagram and test output (group activity) |

**Run:** `javac *.java && java Main` inside each folder.
